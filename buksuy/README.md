# БУКСУЙ

Игра про старую машину, которой надо доехать до Северного города. Машина ломается,
бензин кончается, на дороге постоянно что-то происходит. Зачем ехать на север —
никто толком не объясняет. Это надо выяснить самому.

Жанр: приключение + открытый мир + физика машины. Не гонка.

Сделано на Three.js, работает в браузере. Звук синтезируется на лету (WebAudio),
текстуры рисуются в canvas при загрузке — внешних ассетов нет.

## Запуск

Нужен Node.js 18+.

```bash
cd buksuy
npm install
npm run dev        # http://localhost:5173
```

Сборка в статику (можно положить на любой хостинг, пути относительные):

```bash
npm run build      # результат в dist/
npm run preview
```

Тесты физики и мира (без браузера):

```bash
npm test
```

## Управление

| Клавиша | Действие |
|---|---|
| W / S | газ / тормоз, задний ход (подержать S стоя) |
| A / D | руль |
| Пробел | ручник (пешком — прыжок) |
| F | сесть в машину / выйти |
| E | действие: поговорить, открыть капот, обыскать, заправиться |
| Q | завести / заглушить двигатель |
| L | фары |
| R / Shift+R | радио: следующая станция / выключить |
| H | гудок |
| C | камера (за машиной, дальняя, с капота) |
| B | бардачок |
| Z | поспать в машине |
| G (держать) | толкать машину |
| Tab или I | вещи и багажник |
| M | карта |
| J | журнал: задания, записки, радио, достижения |
| Esc / P | пауза |
| F5 / F9 | быстрое сохранение / загрузка |
| мышь | обзор (клик по экрану захватывает курсор) |

## Что есть в игре

**Машина.** Ласточка — заднеприводная, 50 л.с., автомат с характером. Подвеска на
лучах, шины с моделью сцепления и пробуксовки, двигатель с кривой момента,
сцепление, перегрев, масло, аккумулятор, генератор. Повреждения считаются по зонам
удара и реально влияют на езду: слабые тормоза — длиннее тормозной путь, убитая
подвеска — трясёт и раскачивает, спущенное колесо — тянет в сторону, разбитая
фара — ночью темно. Бампер, двери, капот, крышка багажника, зеркала, глушитель
и колёса отваливаются и остаются лежать на дороге — их можно подобрать и
поставить обратно. Без крышки багажника вещи вылетают на кочках.

**Ремонт.** Капот открывается клавишей E у передка машины. Для ремонта нужны
инструменты и детали. Деталь можно купить, найти, снять с брошенной машины или
заменить чем-нибудь: колготки вместо ремня генератора, изолента вместо патрубка,
вода вместо антифриза (до первого мороза). В мастерских чинят за деньги, там же
ставят улучшения: двигатель, подвеску, шины, бак, тормоза, багажник на крышу,
кенгурятник.

**Мир.** Примерно 2 × 5 км: деревня, заправки, кафе для дальнобойщиков,
автосервис, река с мостами и бродом, болото, лес, горный серпантин, заброшенный
завод, радиовышка, узкоколейка с тоннелем, замёрзшее озеро, КПП и сам Северный
город. Смена дня и ночи, погода (ясно, облачно, дождь, гроза, туман, снег) —
мокрый асфальт и снег меняют сцепление, туман и ночь — видимость.

**Люди.** Дядя Миша, механик Гена, заправщица Люда, дальнобойщик Валера,
дед Ефим, рыбак Семёныч, тётя Зина, баба Нюра, сторож Борис, прапорщик Сидоренко
и случайные встречные. У каждого свои диалоги и своя история.

**Случайные события.** Проколы, попутчики, сломанная машина на обочине, гроза,
упавшее дерево, брошенная заправка, торговец, находки в кювете, авария, скрытые
дороги, старый гараж, странная радиопередача, внезапные поломки, корова, лось,
человек в плаще, которого ты уже где-то видел…

**Радио.** Музыкальная станция, новости (прогноз погоды сбывается, а про обвал
на серпантине лучше послушать заранее), разговорное шоу и неизвестная частота.
Если в браузере есть русский голос, радио говорит вслух.

**Карта** открывается по мере езды, на ней можно ставить свои метки.

**Сохранение** — автосохранение, быстрое и три слота, плюс выгрузка в файл.
Хранится всё: машина по деталям, топливо, инвентарь, найденные места, задания,
сюжет, отношения с людьми, туман на карте.

**Концовки.** Их шесть. Основная — доехать. Остальные — найдёшь.

## Как устроен код

```
src/
  core/      Game (главный цикл), Input, Settings, EventBus, утилиты, шум
  world/     WorldLayout (ручная разметка карты), Terrain, Roads, Ground,
             Colliders, рендер рельефа/дорог/воды/неба, Vegetation, Structures,
             DayNightSystem, WeatherSystem, Effects, WorldManager
  vehicle/   VehicleController (физика), VehicleDamage, VehicleRepair,
             FuelSystem, VehicleConfig (улучшения), VehicleModel, Debris, CarEffects
  player/    PlayerController, CameraRig, Humanoid
  systems/   Inventory, Interactions, NPCSystem, DialogSystem, QuestSystem,
             RandomEvents, RadioSystem, MapSystem, SaveSystem, Achievements,
             Story, Economy, Needs, WorldInteractions
  data/      предметы, персонажи, диалоги, задания, места, радио, концовки
  audio/     AudioSystem (синтез звуков и мотора), Music (музыка для радио)
  ui/        UIManager и панели (ремонт, багажник, карта, журнал, меню…)
```

Физика машины не зависит от рендера и гоняется в тестах прямо в Node
(`tests/vehicle.test.js`). Мир генерируется детерминированно из сида, поэтому
сохранения не ломаются.

Добавить персонажа — запись в `data/npcs.js`, диалог в `data/dialogs.js`
и точку в `world/Structures.js`. Добавить случайное событие — ещё один
`ev(...)` в `systems/RandomEvents.js`.

## Производительность

На слабом компьютере поставь в настройках качество «Низкое» и дальность
прорисовки поменьше — уменьшатся плотность леса, разрешение и тени.
