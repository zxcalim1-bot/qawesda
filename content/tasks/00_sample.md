## Условие
Дано натуральное число N. Найдите сумму его цифр.
## Входные данные
Одна строка — число N (1 ≤ N ≤ 10^18).
## Выходные данные
Одно число — сумма цифр.
## Примеры
```in
12345
```
```out
15
```
## Подсказки
- Последняя цифра числа — остаток от деления на 10.
- После того как цифра учтена, её можно «отрезать»: n // 10.
- Повторяйте, пока число не станет 0, накапливая сумму.
## Решение: цикл while
@time: O(log N) @memory: O(1)
Отделяем цифры с конца.
```python
n = int(input())
s = 0
while n > 0:
    s += n % 10
    n //= 10
print(s)
```
## Решение: строка
@time: O(log N) @memory: O(log N)
```python
print(sum(map(int, input().strip())))
```
## Объяснение
n % 10 даёт последнюю цифру, n // 10 убирает её.
